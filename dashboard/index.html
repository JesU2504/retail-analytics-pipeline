    What the numbers mean

    Revenue includes completed lines after discounts. Cancelled lines stay in the warehouse and contribute zero.

    Customers and products use current attributes (SCD type 1). Distinct order counts across categories are not additive.

    Snapshot, not a live warehouse

    The browser does not run Python, ingest new data or query a cloud database. Rebuild and re-export the pipeline to publish updated results.
